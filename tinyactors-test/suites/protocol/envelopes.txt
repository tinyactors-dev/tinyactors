# Envelopes between systems (docs/protocol.md, Envelope): what
# ta_host_envelope writes and ta_host_envelope_read / ta_host_peer_error_read
# take. Run by the suite's runner and core's run_protocol.c.
#
# A case is a line "<kind> <name>", then:
#   setup <name>      the host (README.md, "Setups")
#   cbor <hex>        an envelope or error envelope, as CBOR
#   back <hex>        roundtrip: what is written back, when it is not `cbor`
#   envelope <hex>    send, relay: the envelopes the host writes, in order
#   diag <text>       the hex line before it, in diagnostic notation
# The kinds:
#   send              the setup's run writes these envelopes (PEER effects)
#   roundtrip         read, then written again: the same bytes (or `back`)
#   invalid           ta_host_envelope_read refuses it (TA_ERROR_INVALID)
#   error-roundtrip   as roundtrip, an error envelope
#   error-invalid     ta_host_peer_error_read refuses it
#   relay             the "relay" host ("b") takes it from peer "a" for "c"
#                     and writes these envelopes on to "c"
#   refused           the "relay" host takes it from peer "a", refuses it,
#                     and writes these error envelopes back to "a"
