# Neutral values (docs/protocol.md, "Values"): event data as CBOR, the form
# a binding's codec and a datamodel's reader and writer share. The runner
# runs them on the datamodel under test: a roundtrip or malformed value is
# given to the echo setup (README.md, "Setups") as the data of an event
# from another system, whose chart sends the event's data back to its
# origin through the remote I/O processor, and that data is compared; encode and invalid
# cases are value.encode's (docs/driver.md), on ECMAScript datamodels. Core's
# tests/unit/test_datamodel_ecmascript.c runs them against the vtable of
# the ECMAScript datamodel (quickjs-ng) too. A datamodel in another language
# passes the roundtrip and malformed cases but those named "ECMAScript: ...";
# an ECMAScript one passes all but those named "not ECMAScript: ...".
#
# A case is a line "<kind> <name>" and the lines after it:
#   cbor <hex>          the value, as CBOR
#   back <hex>          roundtrip: what to_wire writes, when it is not `cbor`
#   diag <text>         the cbor or back line before it in diagnostic notation
#                       (ta_cbor_diagnostic), checked too
#   ecmascript <expr>   a value made by this ECMAScript expression
#   python <expr>       the same value made by this Python expression, where
#                       Python has it: for the Python binding's own tests of
#                       its conversion (value.encode is ECMAScript's)
# The kinds:
#   roundtrip   reading `cbor`, then to_wire, writes `back` (or `cbor`):
#               the echo's send back carries it as its data
#   encode      to_wire of the `ecmascript` value writes `cbor`
#   invalid     to_wire of the `ecmascript` value is TA_ERROR_INVALID
#   malformed   reading `cbor` is TA_ERROR_INVALID: the input is refused
#
# Integers within ±(2^53-1) are numbers in ECMAScript and others BigInts, so
# every integer comes back as itself. ECMAScript has no reference type: a
# reference (tag 32) arrives as its address, and goes back as text. It has
# no integer type either: a float holding an integer comes back as one. A
# language with a reference type and a second empty value (Python's Address
# and UNDEFINED) keeps both: the "not ECMAScript" cases. Text is valid
# UTF-8: a lone surrogate is refused, never replaced, and the UTF-8 form of
# a surrogate (CESU-8) is not text.
