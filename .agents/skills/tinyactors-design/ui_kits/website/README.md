# Website UI kit

Marketing landing + docs for tinyactors. No production site was provided; this is an original design built on the system.

- `Header.jsx` — sticky blurred header, wordmark, version badge, nav, Install CTA
- `Hero.jsx` — dot-grid hero, mono display headline, CodeBlock + clickable StateNode demo
- `Features.jsx` — four-column hairline feature grid, bindings strip, footer
- `DocsPage.jsx` — three-column docs: nav sidebar, prose + language tabs, on-this-page

Click-thru: Install / Get started / Docs → docs page; wordmark → home. Click event tags in the hero to transition the chart.
