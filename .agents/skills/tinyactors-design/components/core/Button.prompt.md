Rectangular action button (4px radius, 13px Plex Sans medium) — use for any clickable command.

```jsx
<Button variant="primary" icon="play">Spawn actor</Button>
<Button>Cancel</Button>
<Button variant="ghost" size="sm" iconRight="arrow-right">Docs</Button>
```

- `primary` pine fill — one per view. `secondary` default. `ghost` toolbars. `danger` outlined red for stop/kill.
- Sizes: sm 26px, md 32px, lg 40px (marketing CTAs).
