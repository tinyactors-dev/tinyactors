tinyactors / interactive laboratory

Keystrokes become states.

A modal editor, a living keymap, one actor. Watch the statechart handle the parts of UI code that usually turn into a pile of flags. Running entirely in your browser, on WebAssembly.

Smaller building blocks Same runtime. Same event → state → render pattern.

Toggle

On, off — and a guard that ignores clicks while disabled.

Counter

Bounded 0–20. Hold a button: after a delay it repeats (delayed transitions), and stops at the bound.

Autocomplete

Debounced; the "server" answers slowly, and answers to old queries are dropped. Arrow keys, Enter, Esc.

Form

Every field is an actor that validates itself and reports to the form's actor; submit unlocks when all are valid.

Dialog

Opening and closing are states of their own with a duration — the element only animates them.

200 counters, hibernated off-screen

Counters scrolled out of view are hibernated — unloaded from the runtime into a store. Scroll back and use one: it wakes up with its value.
